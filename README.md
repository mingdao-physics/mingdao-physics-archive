# 明道物理科檔案室

明道中學物理科內部檔案室：考卷、模擬考、考古題、科務會議資料與其他科務文件的目錄。單一 `index.html` 靜態網頁，不需要伺服器，用瀏覽器打開就能用。

線上版：https://yi-hung-bit.github.io/mingdao-physics-archive/

## 資料怎麼存

- 目錄資料存在各自瀏覽器裡（localStorage），每位老師打開的是自己那一份。
- 要交接或備份：用頁面上的「匯出目錄」存成 JSON 檔，對方用「匯入目錄」接手。
- 上傳的檔案本體只存在上傳那台裝置的瀏覽器裡（IndexedDB，25 MB 上限）；要全科共用同一份檔案，檔案放雲端硬碟、卷宗用「連結」方式登記。

## 本機使用

直接用瀏覽器打開 `index.html` 即可。也可以下載後放在桌面，點兩下開啟。

## 和「教學檔案室」的差別

這是物理科專用的檔案室，色調改為深藍鋼青色系，資料儲存位置與教學檔案室完全分開，兩邊的目錄不會互相干擾。
